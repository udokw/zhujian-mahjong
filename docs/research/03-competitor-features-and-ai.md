# 竞品功能清单、新手引导与四级 AI 设计

> 说明：竞品信息来自公开资料、应用商店介绍与产品体验归纳，具体以各产品现版本为准。
> 目标：为「国标 + 广东」双规则麻将确定功能范围，并给出可落地的四级 AI 路线。

---

## 0. 结论摘要

| 问题 | 结论 |
|---|---|
| 竞品功能重心 | 大厅/玩法入口 → 场次/段位 → 好友房 → 对局内体验 → 回放/牌谱 → 成长/商业化 |
| 双规则产品的差异点 | **规则解释成本高**（国标 81 番 + 8 分起和；广东买马/包牌），新手引导必须比日麻产品更重 |
| MVP 必做 | 大厅、两种玩法入口、好友房、人机、断线重连/托管、结算、基础战绩、新手引导 |
| 可后置 | 观战、赛事、俱乐部、装扮商城、牌谱深度分析、赛季 |
| AI 分级 | 新手（合法+随机倾向）→ 普通（向听/牌效）→ 高手（打点+防守+场况）→ 大师（搜索+对手建模+学习） |
| 托管 AI | 用「普通」级 + 防守偏置，**不要**用大师级，避免不公平 |

### 1.4 对本产品的启示

1. **不要一上来做「玩法合集」**。双规则已经足够，先把国标和广东各做透。
2. **广东是拉新入口，国标是留存/竞技**。默认推倒胡，排位国标。
3. **好友房是冷启动关键**。没有匹配池时，好友房 + AI 补位能让用户先玩起来。
4. **回放是规则产品的信任基础**。国标番种复杂，玩家会质疑计分；牌谱可复盘能大幅降低客服成本。
5. **新手引导必须覆盖「为什么不能胡」**。国标 8 分起和、广东买马/包牌，是新手流失高发点。
6. **商业化后置**。先做留存，再做装扮/月卡；否则规则都没讲清楚就卖皮肤，转化差。

## 3. 新手引导设计

### 3.1 目标

让一个没打过麻将的用户在 **5 分钟内**完成一局简化对局，并理解：

1. 目标是凑 4 副面子 + 1 对将；
2. 怎么摸、怎么打；
3. 吃/碰/杠/胡是什么；
4. 为什么这手牌能胡/不能胡；
5. 国标「8 分起和」和广东「鸡胡也能胡」的差异。

### 3.2 分层引导

| 层级 | 形式 | 内容 |
|---|---|---|
| L0 首次启动 | 3 页图文 | 玩法选择、规则差异、操作方式 |
| L1 强制教程 | 分步遮罩 + 只允许正确操作 | 摸牌→打牌→碰→胡 |
| L2 练习模式 | 固定牌局 + 提示 | 听牌提示、番种预览、无限撤销 |
| L3 对局内提示 | 气泡/高亮 | 可胡、可碰、危险牌、番种差几分 |
| L4 规则速查 | 图鉴/计分器 | 81 番种、广东番型、买马/包牌说明 |
| L5 渐进解锁 | 任务 | 完成 3 局推倒胡 → 解锁鸡平胡 → 解锁国标 |

### 3.3 教程脚本（推倒胡）

```text
第 1 步：发牌，高亮手牌，说明「你需要 4 副面子 + 1 对将」
第 2 步：只允许摸牌，展示摸到的牌
第 3 步：只允许打出「西风」，说明孤张
第 4 步：对手打出「三条」，高亮「碰」，只允许碰
第 5 步：碰后自动出牌，说明碰后要打一张
第 6 步：进入听牌，显示「听 2/5 万，剩余 6 张」
第 7 步：自摸，弹出结算，逐项解释「鸡胡 0 番 = 1 倍」
第 8 步：引导进入第一局真实对局（AI 补位）
```

### 3.4 国标专属引导

国标最大的门槛不是操作，是 **8 分起和**。必须做：

- **番种计算器**：手牌实时显示「当前 5 分，还差 3 分」。
- **差几分提示**：听牌时显示「胡了也不够 8 分」。
- **推荐做牌路线**：提示「碰碰和 6 + 断幺 2 = 8」。
- **番种图鉴**：按 88/64/.../1 分组，配牌例。
- **错误解释**：玩家点「胡」但不够分时，明确提示「花牌不计入起和，你只有 7 分」。

### 3.5 广东专属引导

- **买马动画**：结算时展示马牌 → 对应座位 → 输赢复制，必须可视化。
- **包牌提示**：当玩家可能形成「十二张落地」时，提示「你再碰一张，对方自摸你要包三家」。
- **只自摸/可点炮差异**：推倒胡场明确显示「本场只允许自摸」。
- **花牌**：含花场解释「花牌 1 番，补花后胡算自摸」。

## 4. 四级 AI 设计

### 4.1 共同基础

所有等级共用同一套「合法动作 + 规则引擎」，AI **不能看到隐藏信息**（牌墙、对手手牌）。等级差异只体现在决策质量。

```text
AI 输入（玩家视角）：
- 自己的手牌（34 种计数）
- 自己的副露
- 全部牌河
- 全部明副露
- 剩余牌数
- 座位/庄家/圈风/门风
- 分数/局数/巡目
- 响应窗口（可吃/碰/杠/胡）

AI 输出：
- 一个合法动作（discard/chi/peng/gang/hu/pass）
```

### 4.2 四级能力矩阵

| 能力 | 新手 L1 | 普通 L2 | 高手 L3 | 大师 L4 |
|---|---|---|---|---|
| 合法性 | 保证 | 保证 | 保证 | 保证 |
| 和牌 | 能胡就胡（偶尔漏） | 能胡就胡 | 比较自摸/荣和收益 | EV 最优 |
| 向听数 | 不算 | 会算 | 会算 | 会算 |
| 有效牌（ukeire） | 不算 | 会算 | 会算 + 加权 | 会算 + 概率 |
| 牌效 | 孤张/边张优先 | 进张数最大 | 进张 × 打点 | 全局 EV |
| 番种规划 | 无 | 会做鸡胡/平胡 | 会规划 8 分路线/大牌 | 多路线动态规划 |
| 防守 | 无 | 现物/字牌 | 筋/壁/危险度表 | 对手手牌推断 |
| 副露 | 见碰就碰 | 简单评估 | 速度/打点/防守权衡 | EV 权衡 |
| 杠 | 见杠就杠 | 简单评估 | 考虑杠上开花/抢杠/包牌 | EV + 风险 |
| 场况 | 忽略 | 忽略 | 看点数/巡目/庄家 | 顺位/收支/赛季 |
| 对手建模 | 无 | 无 | 舍牌倾向 | 贝叶斯/神经网络 |
| 计算 | 规则启发 | 向听 + 枚举 | 蒙特卡洛/危险度 | MCTS + 学习模型 |
| 延迟 | <10 ms | <50 ms | <300 ms | 0.5–3 s |
| 实现 | 手写规则 | 手写 + 枚举 | 模拟/评估函数 | 离线训练 + 推理 |

### 4.3 各级详细设计

#### L1 新手

**目标**：像刚学会规则的人，能打完，但会犯错。

决策：

1. 能胡就胡（小概率漏胡，制造「新手感」）。
2. 出牌：优先打孤张字牌/幺九，其次打边张；同价值随机。
3. 碰/杠：有就做，不评估。
4. 不做防守，不给对手让牌。
5. 不做番种规划；国标下经常「听牌但不够 8 分」。

实现：

```text
score(tile) = 孤张权重 + 边张权重 + 字牌权重 + random
选择 max score 打出
```

注意：新手不是「作弊变弱」，而是**策略浅**；合法性必须 100%。

#### L2 普通

**目标**：会打牌，懂牌效，但不精算。

决策：

1. 计算向听数（shanten），选择使向听数最小/不变且有效牌最多的打出。
2. 有效牌 = 使向听数减少的牌 × 剩余张数。
3. 会做基本牌型：鸡胡、平胡、碰碰和、混一色。
4. 简单防守：优先打现物、字牌、已见 3 张的牌；不做危险度精算。
5. 碰/杠：能提速就碰；国标下考虑是否够 8 分。
6. 听牌：选择待牌张数最多的听法。

实现：

```text
for each legal discard:
    shanten = calcShanten(hand - tile)
    ukeire = countEffectiveTiles(hand - tile)
    score = -shanten * 1000 + ukeire * 10 + safetyBonus(tile)
pick max
```

这是**托管 AI 的推荐等级**：够用、不点炮太离谱、不碾压玩家。

#### L3 高手

**目标**：会算打点、会防守、会看场况。

决策：

1. 手牌价值 = 向听 + 有效牌 + **番种期望**（国标 8 分路线、广东大胡）。
2. 听牌选择：比较「待牌数 × 平均打点」而不是只看张数。
3. 防守：危险度模型
   - 现物 = 0；
   - 字牌/幺九 = 低；
   - 筋牌 = 中；
   - 中张无筋 = 高；
   - 对手副露/立直/听牌信号 = 加权。
4. 副露判断：比较「副露后速度提升」vs「打点下降/防守变差/包牌风险」。
5. 杠判断：考虑杠上开花、抢杠、杠后手牌变化、广东包牌。
6. 场况：点数、巡目、庄家、剩余牌数；领先时保守，落后时进攻。
7. 对手建模：统计对手舍牌、副露、胡牌倾向。

实现：

- 评估函数 + 1–2 层搜索；
- 或 determinized MCTS（抽样未知牌，模拟若干局）；
- 危险度表可用统计/牌谱训练得到。

#### L4 大师

**目标**：接近高水平人类/强 AI。

决策：

1. **不完全信息搜索**：对未知牌做一致性抽样（determinization），跑 MCTS/CFR 类搜索。
2. **对手手牌推断**：根据舍牌、副露、动作时序，维护每种牌在对手手中的概率。
3. **联合优化**：进攻（和牌率/打点）与防守（放铳率）统一到 EV。
4. **场况 EV**：顺位、点数、赛季积分、比赛规则（需要保分/追分）。
5. **可控风格**：激进/保守/均衡，通过 reward 或温度参数调节。
6. **学习**：
   - 第一阶段：监督学习（牌谱模仿）；
   - 第二阶段：自我对弈强化学习（奖励 = 顺位/得分，放铳惩罚）；
   - 第三阶段：蒸馏到小模型，端上/服务端推理。

实现路线：

```text
离线：
  牌谱清洗 → 状态编码 → 行为克隆 → 自我对弈 RL → 模型蒸馏
在线：
  状态编码 → 策略网络（候选动作概率）+ 价值网络（胜率/打点）
           → 结合规则约束 → 选择动作
  高算力：MCTS 展开 + 网络评估
  低算力：直接策略网络 + 规则兜底
```

工程建议：

- L4 不要一开始就上。先用 L2/L3 把产品跑起来，积累牌谱后再训练。
- L4 只用于高段位 PvE/赛事解说，不要用于普通匹配（玩家体验差）。
- 端上推理用 ONNX Runtime Mobile / TFLite / Core ML；模型量化到 <20 MB。
- 服务端推理便于统一版本和防作弊，但增加延迟与成本。

### 4.4 国标 AI 的特殊难点

| 难点 | 说明 | 应对 |
|---|---|---|
| 8 分起和 | 听牌 ≠ 能胡 | AI 必须维护「当前番种分」与「可提升路线」 |
| 番种组合爆炸 | 81 番种 + 不计关系 | 用规则引擎的 `scoreHand` 做精确评估，不要近似 |
| 花牌 | 不计起和 | 评估时把花分单独加 |
| 不重复原则 | 容易高估 | 直接调用引擎计分，保证与结算一致 |
| 防守收益低 | 国标点炮损失相对小 | 防守权重低于日麻，但终局/大牌仍需防 |
| 做牌路线 | 清一色/碰碰和/全带幺等 | 用「路线模板 + 完成度」评估 |

### 4.5 广东 AI 的特殊难点

| 难点 | 说明 | 应对 |
|---|---|---|
| 鸡胡 vs 大胡 | 速度与打点权衡 | 按番数期望 + 剩余巡目决策 |
| 只自摸（推倒胡） | 不能靠点炮 | 更重视听牌速度与自摸率 |
| 买马 | 随机，不影响出牌 | 不影响决策；结算单独算 |
| 包牌 | 送牌可能包三家 | 避免让对手形成 12 张落地/大三元/大四喜 |
| 一炮多响 | 点炮可能赔多家 | 危险牌权重更高 |
| 杠分 | 杠有额外收益 | 评估杠的即时收益 vs 手牌损失 |

### 4.6 难度校准

不要用「让 AI 看牌/作弊」来调难度。推荐：

| 等级 | 校准方式 |
|---|---|
| 新手 | 策略浅 + 5–10% 随机次优动作 |
| 普通 | 完整牌效，防守弱 |
| 高手 | 完整评估 + 防守 |
| 大师 | 搜索 + 学习模型 |

验收：

- 同级 AI 自对弈 10,000 局，胜率应接近 25%（四人麻将）；
- L2 对 L1 胜率 ≥ 35%；
- L3 对 L2 胜率 ≥ 32%；
- L4 对 L3 胜率 ≥ 30%；
- 所有等级放铳率：L1 > L2 > L3 > L4（单调）。

### 4.7 托管 AI

- 使用 **L2 + 防守偏置**：
  - 优先打现物/字牌；
  - 不轻易杠（避免抢杠/包牌）；
  - 能胡就胡；
  - 不做高风险副露。
- 延迟 <100 ms，避免玩家等待。
- 玩家回来立即取消托管，不改变已发生的动作。
- 托管期间服务端照常计时，不暂停其他三家。
