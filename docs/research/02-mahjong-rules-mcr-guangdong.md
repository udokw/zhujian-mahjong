# 国标麻将与广东麻将规则调研、默认规则集与边界清单

> 依据：
> - 《中国麻将竞赛规则（试行）》1998 年 7 月国家体育总局审定版（下称「国标原规则」）
> - 腾讯 QQ 广东麻将（鸡平胡）规则、QQ 广东推倒胡规则
> - 国标计番通行释义（不重复、就高不就低、不相同、不拆移、套算一次）
>
> 目标：给「国标 + 广东」双规则产品一份可直接落代码的规则说明，重点标注实现边界。

---

## 0. 结论摘要

| 项 | 国标（MCR） | 广东（推荐默认） |
|---|---|---|
| 牌张 | **144 张**（136 + 8 花） | **136 张**（推倒胡）或 **144 张**（含花变体） |
| 吃 | 可吃（上家） | 推倒胡**不可吃**；鸡平胡可吃（下家） |
| 和牌门槛 | **8 分起和**，花牌不计入起和 | 无番门槛，鸡胡 0 番也可胡 |
| 计分 | 81 番种相加 + 底分 8 | 番 = 2 倍，封顶 3 番（可配） |
| 庄家 | **不连庄** | **连庄**（胡牌或荒庄） |
| 一炮多响 | **不允许**，只取逆时针最近一家 | 鸡平胡允许；推倒胡只许自摸，不存在 |
| 抢杠 | 只抢**加杠** | 只抢**加杠**（推倒胡：只抢自摸形成的明杠） |
| 包牌 | 无 | 有（十二张落地、大三元/大四喜、抢杠、杠上开花、一炮三响） |
| 买马 | 无 | 推倒胡有（庄家买马） |
| 花猪 | 无 | **不是广东规则**，属四川麻将；默认关闭 |
| 天听/地听 | 无 | **不是广东标准规则**，属台湾/大众变体；默认关闭 |

**一句话建议**：
- 竞技/排位 → 「国标标准场」（MCR 1998，144 张，8 分起和，不连庄）。
- 休闲/快速 → 「广东推倒胡」（136 张，不吃，只自摸，3 番封顶，连庄，买马）。
- 经典/好友房 → 「广东鸡平胡」（可吃可点炮，3 番封顶，一炮多响，包牌）。

## 1. 通用基础模型

### 1.1 牌张编码

建议内部统一为 34 种牌 + 8 花：

| 区间 | 含义 |
|---|---|
| `0..8` | 一万..九万（m） |
| `9..17` | 一筒..九筒（p） |
| `18..26` | 一条..九条（s） |
| `27..30` | 东、南、西、北 |
| `31..33` | 中、发、白 |
| `34..41` | 春、夏、秋、冬、梅、兰、竹、菊 |

- 每种普通牌 4 张，共 136 张。
- 国标加 8 花 = 144 张。
- 广东推倒胡默认 136 张；含花变体 144 张。

### 1.2 座位与方向

| 概念 | 定义 |
|---|---|
| 座位索引 | 0=东（庄）、1=南（下家）、2=西（对家）、3=北（上家） |
| 行牌方向 | 逆时针：东 → 南 → 西 → 北 |
| 下家 | `(seat + 1) % 4` |
| 对家 | `(seat + 2) % 4` |
| 上家 | `(seat + 3) % 4` |
| 圈风 | 东/南/西/北，每圈 4 局 |
| 门风 | 庄家为东，下家南，对家西，上家北 |

> 实现注意：UI 底部是「自己」，右家是下家（逆时针），不要和屏幕顺时针混用。

### 1.3 发牌与牌墙

- 洗牌：服务端生成随机种子，Fisher–Yates 洗 144/136 张。
- 发牌：庄家 14 张，闲家 13 张。
- 牌墙：建议用 `ArrayDeque`/双指针，**头部正常摸牌，尾部补花/补杠**。
- **牌尾补牌**是国标和广东的共同点，必须单独建模，不能只用「下一张」。

```text
wall = [t0, t1, ..., tN]
draw()        -> wall.removeFirst()
drawTail()    -> wall.removeLast()   // 补花、开杠补牌
```

### 1.4 补花（国标 / 含花广东）

国标原规则：

1. 起手补花顺序：**庄家 → 南 → 西 → 北**，依次补完。
2. 摸牌后摸到花牌 → 立即补花，**从牌墙尾部**补。
3. **吃、碰后不能补花**；只有摸牌后才能补。
4. 花牌可以连续补、缓补，甚至不补直接打出（线上通常强制自动补）。
5. **补花抓进的牌成和 = 自摸**，不计杠上开花。
6. 花牌每张 1 分，**不计入 8 分起和**，和牌后才计。

实现建议：

- 维护 `pendingFlowerReplacements` 队列；发牌后按座位顺序处理。
- 补花可能连续触发（补到花），循环直到非花。
- 补花后手牌数不变（花牌移出，补一张进手）。
- 补花期间不能吃碰杠；补完才进入正常出牌。

### 1.5 开杠与补牌

| 规则点 | 正确做法 |
|---|---|
| 补牌位置 | **牌墙尾部**，不是头部 |
| 可杠时机 | 吃/碰后必须先舍牌，**不能立即杠**；加杠/暗杠只能在摸牌后 |
| 明杠 | 别人打出第 4 张，或摸到与已碰刻子相同的第 4 张（加杠） |
| 暗杠 | 自己摸齐 4 张，扣放；局末亮明 |
| 杠后补到花 | 先补花，再继续；若补花后成和，只计自摸，不计杠上开花 |
| 杠后补牌成和 | 杠上开花（国标 8 分；广东按番/大胡） |

> 边界：**杠后补牌是从牌尾拿的**，这会改变「最后一张牌」的判定。海底/妙手必须以实际摸到的最后一张为准。

## 2. 国标麻将（MCR）

### 2.1 和牌条件

1. **基本牌型**（4 副面子 + 1 将）：
   - `11 + 123×4`
   - `11 + 123×3 + 111`
   - `11 + 123×2 + 111×2`
   - `11 + 123 + 111×3`
   - `11 + 111×4`
2. **特殊牌型**：
   - 七对：`11×7`
   - 十三幺：13 种幺九字牌各 1 张 + 其中 1 张作将
   - 全不靠：14 张互不靠的单张（详见番种表）
3. **起和分 8 分**：番种总分 ≥ 8 才能和。
4. **花牌分不计入起和分**；和牌后花牌分才加入基本分。
5. **一盘只能有一位和牌者**：多家同时表示和牌时，从打牌者按逆时针方向，**顺序在前者**为和牌者。

### 2.3 五条计分原则（最容易写错）

#### 原则 1：不重复原则

> 当某个番种，由于组牌的条件所决定，在其成立的同时，必然并存在着其他番种，则其他番种不重复计分。

正确理解：

- 是「A 的定义必然包含 B」才不计 B，不是「A 和 B 同时出现就只取一个」。
- 必然包含 **N 次**，就不计 N 个 B；不是把 B 全部封杀。
- 只适用于**单个番种与其他番种**的必然包含，不适用于多个番种组合后与其他番种的包含。

例：
- 大四喜必然包含碰碰和、圈风刻、门风刻、幺九刻 → 这些不计。
- 大三元必然包含 3 个幺九刻 → 这 3 个不计；第 4 副若是幺九刻，仍可计。
- 绿一色 + 清一色 同时出现时，虽然必然断幺，但仍计断幺（因为不是单个番种的必然包含）。

#### 原则 2：就高不就低

一副牌有多种拆分方式时，**每种拆分分别计分，取最高分**。

```text
best = 0
for each decomposition of hand into 4 melds + pair:
    score = scoreFan(decomposition)
    best = max(best, score)
```

这是国标实现的核心：不能贪心先拆一个看起来大的番种就结束。

#### 原则 3：不相同原则

已经组合过某番种的牌，不能再和另一副牌组成**相同番种**计分。

例：一色三步高 + 连六 可以；一色三步高 ×2 不行。

#### 原则 4：不拆移原则

确定一个番种后，不能把它自身拆开再组成新番种计分。

#### 原则 5：套算一次原则

未组合过的一副牌，只能和已组合过的相应一副牌套算一次。

> 实现建议：不要写「if 清一色 then +24」这种平铺判断。正确做法是：
> 1. 枚举所有合法拆分；
> 2. 对每种拆分跑番种识别；
> 3. 用「不计」依赖图去重；
> 4. 取最高总分；
> 5. 加上花牌分。
>
> 番种识别建议做成「模式匹配 + 位掩码」，每个番种一个 `matches(hand, decomposition)`，不要互相调用。

### 2.4 结算

| 项 | 规则 |
|---|---|
| 底分 | 8 |
| 基本分 | 番种总分（含花牌分） |
| 自摸 | 三家各付 `8 + 基本分` |
| 点和 | 放炮者付 `8 + 基本分`，另两家各付 `8` |
| 荒庄 | 不计分 |
| 庄家 | **不连庄**（无论是否和牌） |
| 圈 | 每人坐庄一次为一圈，4 局一圈 |

## 3. 广东麻将

### 3.1 派系与差异

| 派系 | 用牌 | 吃 | 点炮 | 特点 |
|---|---|---|---|---|
| 推倒胡（深圳/东莞） | 136（无花） | **不可吃** | **只许自摸** | 鸡胡、杠分、买马、连庄 |
| 鸡平胡（珠三角） | 136 或 144 | 可吃（下家） | 可点炮 | 鸡胡/平胡/爆胡 3 番、一炮多响、包牌 |
| 新章/老章 | 144 | 可吃 | 可点炮 | 番种更多，地区差异大 |

本产品建议只做两套预设：**推倒胡** 与 **鸡平胡**，新章/老章不做。

### 3.2 推倒胡默认规则

| 项 | 默认值 | 可配置 |
|---|---|---|
| 牌张 | 136（无花） | 144 + 花 |
| 吃 | 禁止 | 开/关 |
| 碰/杠 | 允许 | 开/关 |
| 和牌方式 | **仅自摸 + 抢杠** | 允许点炮 |
| 鸡胡 | 0 番，可胡 | — |
| 番 | 2 倍制 | — |
| 封顶 | 3 番（8 倍） | 3/4/5 番 |
| 连庄 | 胡牌或荒庄连庄 | 开/关 |
| 买马 | 开（庄家） | 开/关，马数上限 |
| 杠分 | 放杠赔 3；明杠每家 1；暗杠每家 2 | 可调 |
| 一炮多响 | 不存在（只自摸） | — |
| 漏胡 | 不存在（只自摸） | — |

计分（QQ 推倒胡）：

- 基础分 1。
- 自摸：基础分 ×2。
- 小胡：基础分 ×1。
- 大胡：基础分 ×2。
- 杠分单独累加：放杠 3 分给杠者；明杠每家 1；暗杠每家 2；可累积。
- 牌型之间**不累积**（取最大牌型）。

| 小三元/小四喜 | 5 番 | — |
| 字一色/清幺九/大三元/大四喜/九莲宝灯/十三幺 | 6 番 | — |
| 爆胡封顶 | 3 番 | 3/4/5 番 |
| 自摸 | +1 番（封顶内） | 开/关 |
| 门风刻/圈风刻/箭刻 | +1 番/个（封顶内） | 开/关 |
| 一炮多响 | 允许 | 开/关 |
| 包牌 | 开 | 开/关 |
| 连庄 | 胡牌/荒庄连庄 | 开/关 |
| 买马 | 关（鸡平胡通常不买） | 开/关 |

计分：

- 番 = 2 倍：`分值 = 2^番`。
- 爆胡 3 番 = 8 倍；特殊牌型（十三幺等）可突破封顶，且不再叠加其他番种。
- 自摸/风刻/箭刻等附加番只在爆胡内有效，不能突破封顶。
- 花牌（144 变体）：每花 1 番或固定 1 分，需配置；补花后胡牌算自摸，不算杠上开花。

### 3.4 买马

QQ 推倒胡的买马规则（建议照此实现，做成开关）：

1. **只有庄家买马**。
2. 庄家第一局必须买 1 匹；连庄则下一局买 2 匹，依次累积，**最多 4 匹**。
3. 买马牌在**发完牌后从牌墙末尾确定**，先不公开，结算时公布。
4. 马牌**从牌墙中移除**，玩家不能摸到。
5. 对应关系：以庄家为起点，按牌面数字 1=庄、2=下家、3=对家、4=上家，循环；字牌按 东、南、西、北、中、发、白 顺序，从庄家起逆时针对应。
6. 结算：马对应玩家本局总输赢（含胡牌与杠分）是多少，庄家就同额输赢；多匹马累加。

容易错的点：

- **马牌先移除，会减少牌墙数量**，直接影响荒庄时点和「最后一张牌」。
- 马牌在结算前必须保密；不能下发给客户端。
- 连庄马数累积规则各平台不同（+1 还是翻倍），必须配置化，不要写死。

### 3.5 包牌

「包」= 由一名玩家承担其他家应付的全部或部分分数。广东鸡平胡常见包牌：

| 场景 | 责任 |
|---|---|
| 一炮三响 | 点炮者包三家 |
| 杠上开花（放杠） | 放杠者包三家 |
| 十二张落地包自摸 | 使他人形成 12 张落地并单吊的打出者，包该玩家自摸的三家份额 |
| 大四喜 | 已碰出 3 副风刻，打出第 4 副者包自摸 |
| 大三元 | 已碰出 2 副箭刻，打出第 3 副者包自摸 |
| 抢杠 | 被抢杠者包三家 |

「包先不包后」：如果 A 先使 B 十二张落地，之后 A 又使 C 十二张落地，A 只包 B，不包 C。

实现建议：

```text
baoResponsibility: Map<winnerSeat, payerSeat>
```

结算时先算总应付，再把责任人的份额替换为「代付三家」。

### 3.6 一炮多响

| 规则集 | 行为 |
|---|---|
| 国标 | **不允许**；按逆时针顺序取最近一家 |
| 广东鸡平胡 | 允许；可配置「几家同时胡」 |
| 广东推倒胡 | 只许自摸，不存在 |

边界：

- 一炮多响包含庄家时，下一局庄家继续（QQ 规则）。
- 付款：点炮者给每个胡牌者各付一份；「一炮三响」按包三家处理。
- 响应窗口内要收集所有胡牌意图，不能收到第一个就立即结算。

### 3.7 荒庄与连庄

| 规则集 | 荒庄处理 |
|---|---|
| 国标 | 不计分，**庄家不连庄**，轮转 |
| 广东推倒胡 | 荒庄**连庄** |
| 广东鸡平胡 | 荒庄**连庄**（可配） |

荒庄判定：牌墙摸完，最后一张打出后无人和。含花/买马时，以**实际可摸牌墙**为准。

### 3.8 花牌

- 广东 144 变体才有花。
- 起手补花；摸到花立即补；从牌尾补。
- 花牌通常计 1 番或固定分（配置）。
- 补花后胡牌算自摸，不算杠上开花。
- 136 推倒胡没有花，不要实现「补花」分支。

### 3.9 天和、地和、人和

| 名称 | 定义 | 默认番 |
|---|---|---|
| 天和 | 庄家起手 14 张（含补花后）即成和 | 6 番（广东）/ 大胡 |
| 地和 | 闲家第一巡自摸第一张牌成和，且此前无人吃碰杠 | 6 番 |
| 人和 | 庄家打出的第一张牌，闲家点和 | 6 番 |

边界：

- 天和必须在补花完成后判定。
- 地和要求「第一巡、无人动牌」；一旦有人吃/碰/杠，失效。
- 人和是点和，不是自摸；付款按点和规则。

### 3.10 漏胡（过水）

广东鸡平胡：

- 玩家听牌后，下家打出可胡的牌却选择不胡，则对家/上家再打同一张时**不能胡**。
- 直到该玩家自己摸牌、碰、吃、杠（动牌）后解除。

推倒胡只许自摸，不存在漏胡。

实现：为每个玩家维护 `passedTiles: Set<Tile>`，动牌时清空。

## 6. 对原需求中两个概念的澄清

### 6.1 「花猪（广东）」不是广东规则

- 花猪是**四川麻将**（血战/血流）的终局检查：胡牌时手牌仍含三门花色，或流局时仍持三门花色，称为花猪，赔给其他玩家 16 倍。
- 主流广东推倒胡/鸡平胡**没有查花猪**。
- 如果产品坚持要「花猪」，只能作为**可选地方变体**，并明确：
  - 判定：终局未胡且手牌仍含三门花色；
  - 赔付：赔给每位非花猪玩家 16 倍；
  - 默认关闭，且在规则说明里标注「四川变体」。

### 6.2 「天听/地听」不是国标/广东标准

- 天听、地听主要见于**台湾麻将/部分大众麻将**：
  - 天听：配牌后未打牌即听牌并宣言；
  - 地听：打出第一张牌后即听牌并宣言。
- 国标 81 番种里没有天听/地听；广东鸡平胡的 QQ 规则里也没有。
- 广东有「天和/地和/人和」，与天听/地听不是一回事。
- 建议：默认关闭；若开启，定义为独立番种、宣言后锁牌、不可换张，番值配置化，并明确是否与门清/不求人叠加。

## 8. 规则引擎实现建议

### 8.1 分层

```text
RuleSet（接口）
├── MCRRuleSet
├── GuangdongTuidaohuRuleSet
└── GuangdongJipinghuRuleSet

核心能力：
- Wall（头摸/尾补/剩余数/最后一张）
- Hand（手牌 + 副露 + 花牌）
- WinChecker（基本型/七对/十三幺/全不靠）
- FanMatcher（番种识别）
- Scorer（拆分枚举 + 不计 + 就高不就低）
- ActionValidator（吃碰杠胡优先级）
- Settlement（底分/番/包/马/杠分）
```

### 8.2 不可变状态 + 动作

```kotlin
data class GameState(
    val wall: List<Tile>,
    val hands: List<List<Tile>>,
    val melds: List<List<Meld>>,
    val discards: List<List<Tile>>,
    val flowers: List<List<Tile>>,
    val turn: Int,
    val dealer: Int,
    val pendingWindow: ResponseWindow?
)

sealed interface Action {
    data class Discard(val seat: Int, val tile: Tile) : Action
    data class Chi(val seat: Int, val tiles: List<Tile>) : Action
    data class Peng(val seat: Int) : Action
    data class Gang(val seat: Int, val type: GangType) : Action
    data class Hu(val seat: Int, val selfDraw: Boolean) : Action
    data object Pass : Action
}
```

- 服务端每次 `apply(state, action)` 返回新状态 + 事件。
- 客户端用同一套函数做动画预测，但以服务端结果为准。

### 8.3 番种识别的工程做法

1. 先把 14 张牌拆成「4 面子 + 1 将」的所有合法组合。
2. 每个番种写一个纯函数 `match(combination, context)`。
3. 用「不计关系表」做去重：

```text
excludes = {
  "大四喜": ["碰碰和", "圈风刻", "门风刻", "三风刻", "幺九刻"],
  "大三元": ["箭刻"],
  ...
}
```

4. 对每种拆分求总分，取最大。
5. 最后加花牌分。

> 不要用「先判断大牌，再判断小牌」的顺序逻辑；那会在复杂牌型上漏算或重复算。
