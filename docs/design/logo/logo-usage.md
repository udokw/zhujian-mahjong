# 竹间麻将 · App 图标用法说明

> 方向 B「节节有牌」定稿 · 2026-11-09 · v1.0

---

## 1. 文件清单

| 文件 | 用途 |
|---|---|
| `zhujian-icon.svg` | 矢量源文件（512×512 viewBox，满幅方图，路径全部手绘，无字体依赖） |
| `icon-1024.png` | App Store / 应用商店主图 |
| `icon-512.png` | 高分辨率通用、商店备用、宣传物料 |
| `icon-180.png` | iOS @3x（iPhone 主屏） |
| `icon-120.png` | iOS @2x（iPhone 主屏）/ Android xxhdpi |
| `icon-60.png` | iOS @3x（设置、通知）/ Android mdpi 附近 |
| `icon-24.png` | 最小尺寸（通知栏小图标、列表缩略） |
| `preview.png` | 资产总览图（浅底 / 深底 / 尺寸阶梯） |
| `drafts.html` | 三方向初稿对比板（存档） |

图标均为**满幅方图**，不带透明通道，圆角由系统遮罩裁切，源文件里不要预先切角。

---

## 2. 标识构成

- **牌形**：竖长方形 + 双线牌框（外框 2、内线 1.6，圆角 28/512），代表一张麻将牌。
- **竹**：牌面上长出一竿三节的竹，顶上一对竹叶。竹在麻将里即「条」，竹与牌在此合为一个图形。
- **竹节金**：只用在三道竹节上，是全图唯一的暖色，负责在深色底上「亮一下」。

造型全部为几何路径，不含文字与字体，任意缩放不失真。

---

## 3. 主色

| 用途 | 色值 | 说明 |
|---|---|---|
| 主色 · 桌绿 | `#174337` | 底色，取自项目牌桌 `table-3`，与启动页、对局桌同源 |
| 牌面 · 象牙 | `#F6F1E7` | 牌身填充 |
| 牌框 | `#D8CDB8` | 双线牌框与内线 |
| 竹 · 玉绿 | `#1F6B52` | 竹竿、竹叶，主题 `primary` |
| 竹节金 | `#E8C97A` | 竹节，主题 `tableGold` |

四个色值全部来自 [Theme.kt](../../../app/src/commonMain/kotlin/mahjong/app/theme/Theme.kt) 的日间令牌，不新增品牌色。

**反白版**：底色换 `#F3EEE3`（宣纸），竹换 `#174337`，竹节换 `#C9A227`，牌身可用 `#FFFFFF`。仅在必须压深色照片或多色背景时使用。

---

## 4. 最小尺寸

- 位图下限 **24px**。24px 时牌框内线与竹叶细节会自然隐去，只剩「白牌 + 绿竿 + 金节」，这是设计好的降级，不是失真。
- 60px 以下不要再用位图放大，改用 `zhujian-icon.svg`。
- 小于 24px 的场景（如状态栏 16–18px）建议不放本图标，或只保留「白色牌 + 单根绿竿」的极简版，另行出图。
- 放大的上限没有限制，矢量在任何尺寸都成立。

---

## 5. 深底 / 浅底适配

图标**自带桌绿底色**，因此可以直接放在任何背景上，不需要额外的底衬或描边。

| 场景 | 处理 |
|---|---|
| 浅色底（宣纸、白、浅灰） | 直接使用。深绿与浅底对比充足（≈11:1），无需描边 |
| 深色底（#0F141B、黑色、深色照片） | 直接使用。图标与深底之间保留至少 **8% 画布**的外边距，避免与背景糊在一起 |
| 多色 / 复杂背景 | 先垫一层纯色矩形（桌绿或宣纸），再放图标；不要把图标直接压在花纹或照片上 |
| 单色印刷（黑白、烫金） | 用「反白版」：去掉底色，牌框、竹竿用单色实心，竹节改同色留白 |

安全边距：图形内容距画布边缘最小 46/512 ≈ **9%**，裁切、遮罩、圆角都不得侵入这个区域。

---

## 6. 使用禁忌

- 不要拉伸、压扁、旋转图标（牌是竖长方形，比例一旦改变就失去「牌」的识别）。
- 不要改主色。需要区分场景时用第 3 节的反白版，不要临时换色。
- 不要给图标加投影、发光、描边、渐变或高光。
- 不要在图标内加文字（「竹间麻将」四个字不进图标，字标另出）。
- 不要把牌框裁掉做成「只有竹竿」的图形，牌形是这套标识的骨架。

---

## 7. 双端落地

**iOS**：直接用 `icon-1024.png`，不要预切圆角，不要带 alpha；小尺寸按 180 / 120 / 60 填入 Asset Catalog。

**Android（自适应图标）**：需要拆两层。
- 背景层：纯色 `#174337`。
- 前景层：复制 `zhujian-icon.svg`，删掉第一行 `<rect width="512" height="512" fill="#174337"/>`，再把牌图形整体缩到画布的 66% 居中（自适应图标的安全区），导出为 432×432 前景图。
- 若暂时不做自适应图标，直接使用 `icon-512.png` 作为 legacy 图标也可正常显示。

**应用内**：大厅左上角等位置按设计规范使用 24dp 圆角裁切，尺寸不小于 32dp。
