四张牌桌，四种坐下来的理由

每款主题都换三样东西：桌面绒布、木沿材质、页面底色与纸张。牌面始终是象牙瓷白，红绿蓝三色照旧——变的只是光打上去的方式。下面每一张牌桌都是用游戏里同一套 60×80 矢量牌面和同一组色值渲染出来的，不是示意图。

切换日间 / 夜间，四款同步换色 色板依次为页面底、卡片、主色、金、桌布、木沿 牌面依次为一萬、五條、九筒、東、中、發
落地方式　色值直接写进 commonMain 的同一张主题表，Android 与 iOS 共用，不做平台分支。 牌面　沿用 60×80 viewBox 的矢量绘制，主题只提供纸色、牌背与三色墨。 牌桌　木沿渐变 + 绒布径向渐变 + 各自织纹，全部由 Canvas 画出，不依赖位图。
